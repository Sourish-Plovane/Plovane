How it works

Trace a change from project map to code diff.

1: Describe the work

Ask for a change in plain English. Claude is included by default, with your request tied to the project you opened.

2: Follow the project

Move from services to folders, files, explanations, and code. Switch layers to inspect file structure, API endpoints, or test health.

3: Review the change

Search sandbox-tested code and insert a match by reference. Or inspect a proposed diff, apply it to Git, and run affected tests.

The Verified Library starts with team code and a verified PyTorch library. Current language focus is Python, PyTorch, and JavaScript. Planned languages include HTML, CSS, C++, and CUDA C++.
