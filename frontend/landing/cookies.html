Cookies and browser storage

Last updated: November 26, 2026

Public site

The landing page code does not set analytics or advertising cookies. Your browser and hosting provider may process standard request data. The public repository cannot confirm production hosting logs or infrastructure settings.

Necessary storage

Some app functions may require strictly necessary storage for operation or security. The public marketing page does not require an account to read.

Local and session storage

The whiteboard app uses browser localStorage for theme mode, accent, layout and other interface preferences, workspace name, provider choice, and some project UI state such as prompt history. These values remain in that browser profile until cleared. The CLI uses sessionStorage for command history, which is scoped to the browser tab session. These browser storage APIs are not cookies, but they can still hold data on your device.

Manage storage

Use your browser settings to clear cookies and site data. Clearing localStorage or sessionStorage may reset preferences or remove locally stored interface history. See the Privacy notice.
